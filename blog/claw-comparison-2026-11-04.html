ZeroClaw and the *-claw Ecosystem: A Factual Comparison

Posted 2026-11-04 · by han · 15 min read

A grounded, source-backed comparison of the personal-AI-agent projects that share the "-claw" name — OpenClaw, ZeroClaw, IronClaw, NanoClaw, NullClaw, MicroClaw, PicoClaw (upstream and fork), NemoClaw, and TinyClaw/TinyAGI. No opinion; every number traced to a GitHub repo page [as of 2026-11-04].

TL;DR

  • The "-claw" family is a loose ecosystem of personal AI agent runtimes that grew out of OpenClaw (the originator, ~394k ⭐). Most are independent rewrites in other languages targeting smaller footprints or stronger isolation.
  • ZeroClaw (Rust, ~33.1k ⭐) is one of the larger Rust rewrites: single binary, 30+ channels, ~20 providers, hardware GPIO/I2C/SPI, an SOP engine, ACP.
  • NemoClaw is not a standalone agent — it's an NVIDIA sandbox wrapper (OpenShell) that runs OpenClaw/Hermes/DeepAgents more safely. Counting it as an "agent" is a category error.
  • PicoClaw has two distinct repos: upstream sipeed/picoclaw (~30.1k ⭐) and an active fork afjcjsbx/picoclaw (47 ⭐). They must not be conflated.
  • NullClaw's benchmark table (RAM/startup/binary size vs. OpenClaw, NanoBot, PicoClaw, ZeroClaw) is project-self-reported [project-reported, NullClaw, Feb 2026]. Treat as marketing, not measurement.
  • NullClaw itself grew from 1.8k (plan-era guess) to 8.2k ⭐ [as of 2026-11-04] — verify star counts on the live page before quoting.

1. What this family is

"Claw" projects are personal AI assistants you run yourself: they talk to LLM providers, reach you over chat channels (Telegram, Discord, Slack, …), and act through tools (shell, browser, files, hardware). The common thread is ownership — your keys, your data, your machine. Beyond that, they diverge sharply on language, size, isolation model, and target hardware.

OpenClaw is the originator and the largest by a wide margin. The others are mostly rewrites that trade OpenClaw's breadth for a smaller footprint, a different language, or a stricter sandbox.

4. Distinctions that matter

4.1 NemoClaw is a sandbox wrapper, not a standalone agent

NemoClaw's own README: "Run agents like Hermes, LangChain Deep Agents, and OpenClaw more securely inside NVIDIA OpenShell." It is a TypeScript CLI + blueprint that provisions an OpenShell sandbox, routes inference, and applies network policy. It does not run an agent loop itself — the agent (OpenClaw/Hermes/DeepAgents) runs inside. Comparing NemoClaw's "stars" or "channels" to ZeroClaw's is comparing a sandbox product to an agent runtime. If you want an agent, NemoClaw is not it; if you want to secure an agent, it is.

4.2 PicoClaw: upstream vs. fork

  • Upstream: sipeed/picoclaw — 30.1k ⭐, 2,584 commits, Go, MIT, "independent open-source project initiated by Sipeed … written entirely in Go from scratch — not a fork of OpenClaw, NanoBot, or any other project."
  • Fork: afjcjsbx/picoclaw — 47 ⭐, 3,275 commits, explicitly labeled "Actively maintained fork" with WebUI/MCP/plugins. It self-describes as a fork; upstream does not endorse it.

Both are MIT, so forking is permitted. But star counts, commit counts, and feature lists are not interchangeable between them. When quoting "PicoClaw has 30k stars," that's the upstream; the fork has 47.

4.3 NullClaw benchmarks are self-reported

The NullClaw README's "Benchmark Snapshot" table (RAM/startup/binary size vs. OpenClaw, NanoBot, PicoClaw, ZeroClaw) is NullClaw's own measurement on its own machine (/usr/bin/time -l on ReleaseSmall builds, Feb 2026, macOS arm64, normalized to 0.8 GHz edge) [project-reported]. It is not an independent benchmark, not reproducible by a third party from the README alone, and it compares NullClaw's best case (ReleaseSmall, static) against others' default distributions. Use it as a directional claim, not evidence.

4.4 NanoClaw's critique of OpenClaw is NanoClaw's own framing

NanoClaw's README says OpenClaw has "nearly half a million lines of code, 53 config files, and 70+ dependencies" with "application-level (allowlists, pairing codes) rather than true OS-level isolation" and "everything runs in one Node process with shared memory." These are NanoClaw's statements about OpenClaw [project-reported by NanoClaw], not independently measured. They're useful as a design-philosophy signal (NanoClaw's whole thesis is "small enough to understand"), but should not be quoted as audited facts.

4.5 OpenClaw is the common ancestor (conceptually)

IronClaw explicitly says it is "a Rust reimplementation inspired by OpenClaw." NanoClaw, PicoClaw, TinyAGI, and MicroClaw all cite OpenClaw as inspiration. NullClaw and ZeroClaw position themselves as independent but target the same niche. NemoClaw wraps OpenClaw. So OpenClaw remains the reference point for feature parity (IronClaw ships a FEATURE_PARITY.md).

5. Where ZeroClaw sits

Grounded facts from ZeroClaw's own README [as of 2026-11-04]:

  • Language: Rust. Single binary. Dual-licensed MIT OR Apache-2.0.
  • Scale: 33.1k ⭐, 5.0k forks, 5,803 commits, 716 issues, 442 PRs.
  • Channels: 30+ (Discord, Telegram, Matrix, email, voice, webhooks, CLI, ACP, …).
  • Providers: ~20 (Anthropic, OpenAI, Ollama, and others).
  • Features: multi-channel agent loop, provider-agnostic with fallback chains/routing, security-first with supervised autonomy + OS sandboxes (Landlock/Bubblewrap/Seatbelt/Docker) + cryptographic tool receipts, hardware (GPIO/I2C/SPI/USB on Pi/STM32/Arduino/ESP32), HTTP/WS gateway + web dashboard, SOP engine (event-triggered procedures with approval gates and resumable runs), ACP (JSON-RPC 2.0 over stdio for IDE integration).
  • Config: one TOML file (~/.zeroclaw/config.toml), V3 shape with <type>.<alias> sections.
  • Install: Unix installer, Windows PowerShell path, Docker, NixOS, source build. (Install commands omitted here per scope; see the repo.)
  • Official repo notice: ZeroClaw Labs declares zeroclaw-labs/zeroclaw the only official repo; any other claiming affiliation is unauthorized.

What ZeroClaw does not publish: a binary size, RAM, or startup figure in its own README. The only such numbers come from NullClaw's self-reported comparison (§3.2), which should be labeled as such.
