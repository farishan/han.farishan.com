Try workflow-kit in 5 minutes ⚡

Posted Nov 6, 2026 · 3 min read

You don't need to read the whole playbook to feel the difference. Clone the free core, run the verifier, and ship one small change through the loop. Five minutes.

1. Clone + install

git clone https://github.com/farishan/workflow-kit.git
cd workflow-kit && bash install.sh

2. Run the verifier

./bin/wf-verify

It auto-detects your stack (Go, Bun/Node, Rust, Deno, Ruby, TS, Make, Python) and runs the right checks. Green means you're ready.

3. Run the loop on one small change

Pick a tiny task. Then:

/spec   # write the spec first
/plan   # break it into tasks
# implement
/verify # must be green
/review # separate reviewer agent
/ship   # commit + push + PR

The point: /verify and /review are mandatory gates, not optional cleanup. That's what makes agent output shippable.
